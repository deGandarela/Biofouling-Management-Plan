# Shipsonic Biofouling Management Plan Generator

This repository contains the web application for the Shipsonic Biofouling Management Plan Generator. Serving as an interoperable digital compliance framework and asset record engine, it allows users to create official compliance documents aligned with international maritime regulations. As a core module of the broader Shipsonic platform for maritime vessel analysis, it streamlines the management of hull operating profiles and tracks spatial biofouling risk parameters.

## Features

* **Step-by-Step Document Generator:** Intuitive navigation through sections for Vessel Particulars, Operating Profiles, Anti-fouling & MGPS Systems, and Inspection schedules.
* **Statutory Compliance Alerts:** Built-in critical warnings, such as NORMAM-401/DPC alerts, which trigger when hull macrofouling equals or exceeds Rating 2, prohibiting navigation in specific biogeographic zones without prior authorization and localized in-water cleaning.
* **Comprehensive Asset Tracking:** Dedicated logs to record active anti-fouling coatings, Marine Growth Prevention Systems (MGPS) hardware specifications, and application lifespans.
* **Contingency & Audit Readiness:** Outlines proactive cleaning activities, operational containment strategies, and contingency frameworks tailored for extended vessel inactivity.

## Compliance & Data Frameworks

The information and documentation generated by this tool are structured to be strictly compliant with major international frameworks, including:

* IMO MEPC.378(80) & PPR 13 Mandatory Framework
* NORMAM-401 / DPC Regulations (Joint Digital Dataset)
* ISO 20679 survey protocols
* AMPP Guide 21517-2025
* BEMA BRADD Data Framework
* Global TestNet MGPS efficacy testing standards (MEPC 83/INF.3)
